Главная мысль, которая снимает дискомфорт: в Python файл = модуль = пространство имён, а точка — это один-единственный оператор «дай мне то, что лежит внутри объекта слева». 
Ему всё равно, что слева: модуль, пакет, класс или экземпляр. Везде одна и та же точка «залезь внутрь и достань атрибут по имени». Грубый перевод на плюсы:
module.thing   ≈   namespace::thing

Точка в pygame.locals. pygame — это не файл, а пакет: папка с кодом. pygame.locals — это файл locals.py внутри этой папки. Точка = «зайди в пакет pygame и возьми оттуда модуль locals». Как вложенный неймспейс pygame::locals.


shapes.py

PI = 3.14159

def area(r):
    return PI * r * r

import shapes            # притащили имя shapes
print(shapes.PI)         # 3.14159 — достаём через точку
print(shapes.area(2))    # ≈ shapes::area(2)

или 

from shapes import PI, area   # вытащили ИЗ модуля конкретные имена наружу
print(PI)                     # теперь без префикса
print(area(2))

или 

from shapes import *          # вытащили ВСЁ наружу
print(PI)
print(area(2))

И теперь главное — pygame.init(). Твоё «мы же нигде не создавали объект» — ключевая точка непонимания. Ты его создал. Вот этой строкой:

python
import pygame

import — это не #include, он делает больше: находит пакет на диске, выполняет его код (один раз), создаёт объект-модуль в памяти и привязывает имя pygame к этому объекту. 
То есть после import pygame имя pygame указывает на живой объект-модуль. 
Конструктор ты руками не звал, но import фактически «загрузил и создал» его за тебя (причём как синглтон — импортни в десяти местах, объект будет один и тот же, он кешируется).

Буквально текст .py-файла, выполненный сверху вниз как скрипт. Не «объявления, которые компилятор учтёт», а инструкции, которые реально исполняются одна за другой в момент импорта. Вот тут и есть корень нестыковки с плюсами: #include вставляет декларации на этапе компиляции и ничего не «запускает», а import в рантайме прогоняет файл целиком.

Покажу на пальцах. Файл demo.py:

python
print("я выполняюсь прямо сейчас, при импорте!")

X = 42

def hello():
    print("hello")

print("а я выполняюсь после def")

Теперь в другом месте просто импортируем — ничего не вызывая:

python
>>> import demo
я выполняюсь прямо сейчас, при импорте!
а я выполняюсь после def
>>> demo.X
42
